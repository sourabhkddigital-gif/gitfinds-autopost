GitFinds Autopost

GitFinds Autopost is a private tool used by the GitFinds team (KD Digital) to publish our own short videos about useful GitHub repositories to the GitFinds YouTube channel and the @gitfinds Instagram account, using a content schedule kept in Google Sheets.

It is used only on accounts we own. It is not offered to the public.
